## 关键实现事实

### DeepSeek Harness SDK（P0-1 / P0-13）

- **精确版本**：`deepseek-harness-sdk==0.1.0rc6`（pin exact prerelease，非 unpinned）。
- **平台限制（如实记录）**：SDK 运行时二进制 `deepseek-harness-runtime-bin` 仅发布 Linux x64/arm64、macOS 14+ arm64；**本机（Windows）无法运行 SDK**。
- **双 Cordis composition**：`harness/physical/cordis.yml`（仅 LLM + agent 核心 + 会话，无 bash/fs/editor/subagent/sandbox）；`harness/development/cordis.yml`（官方 coding 组合，无设备凭据）。
- **集成方式（强化后）**：`DeepSeekHarnessRuntime` 真实实例化官方 `deepseek_harness.DeepSeekHarness`（非 import 检查），经 `cordis=` 加载真实 `.cordis.yml`，`_sane_env()` 剥离设备凭据，subprocess 内 `AGENT_EXECUTION_ENABLED=false`。
- **CI smoke test**：Linux x64 上 `pip install -e ".[dev,harness]"` 后，对本地 fake/model proxy 真实跑一次 `DeepSeekHarness.run()`（不消耗真实 API）；支持平台 SDK 缺失则 FAIL。
- **能力声明（P0-2，如实）**：`native_resume=False`（workaround：host transcript + 新 session）、`native_cancel=True`（subprocess termination）、`tool_bridge=True`（capability.invoke 桥接 gateway）。
- **测试**：platform-gated（Windows 上如实返回 "rejected + 平台说明"，不伪装 completed）。

### 安全栈（P0-3/4/5/7/8/9）

- 写执行闸门 fail-closed：`AGENT_EXECUTION_ENABLED` 缺失/false → 拒绝；true + 完整安全栈 → 允许。
- 审批：`ApprovalRequest`（绑定精确请求 + 参数哈希）→ `ApprovalGrant`（单次/过期/防重放/拒参数篡改）。
- 审计：SHA-256 链 + `load_and_verify()` 启动恢复 + HMAC checkpoint 持久化；损坏 → `_healthy=False` → 写 fail-closed。
- AdapterRegistry：`home.* → HomeAssistantAdapter` 等命名空间路由，gateway 独占。
- correlation_id 唯一 + 幂等 + 并发防重放。
